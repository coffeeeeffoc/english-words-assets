`ready` 仅表示字段齐全，不表示已经过词典专家逐条审校。缺音标词项中，按拼写形态划分有 14 个简单单词或缩写、615 个短语或带标点的词项。不会通过拼接音标、自动改大小写或猜译来隐藏缺失。

## 已有词表

- 人教版小学：三至六年级上下册，8 份。
- 人教版初中：七、八年级上下册与九年级全册，5 份。
- 外研社版初中：七至九年级上下册，6 份。
- 初中／中考综合词表：3 份，包含一个正序与乱序版本；各自保留原始顺序，共享单词记录。

这些是 kajweb 的历史数据。未确认出版年份、课标修订版或具体主编的对应关系。词表没有可靠的单元信息，`unit` 统一为空，`ordinal` 只是来源文件顺序。官方人教版九年级“上册”没有与旧词表“全册”直接匹配。

## 推荐读取方式

| 表或视图 | 内容 |
|---|---|
| `ready_vocabulary` | 首选：教材词表中的单词、中文、音标都非空的记录，包含词表名和来源 |
| `vocabulary` | 所有词表记录，含缺失字段；中文和音标优先用词表原值，缺失才回退基础库 |
| `wordlists` | 22 份词表的名称、版本、年级、册次、类型和核验状态 |
| `words` / `ready_words` | 基础库全部词项／具备中文和音标的词项 |
| `missing_fields` | 词表中字段缺失的逐条清单 |
| `textbooks` / `missing_textbooks` | 官方 379 条资源及对应词表的核验状态；缺口包括未核验候选 |
| `textbook_slots` | 按学段、版本、年级、册次、是否标注 2022 修订聚合成 253 组，仅供排查，不代表严格不同版次 |
| `sources` / `metadata` | 来源网址、固定提交版本和统计摘要 |

```python
import sqlite3

db = sqlite3.connect('英语词库.sqlite')
db.row_factory = sqlite3.Row

# 查看可用词表。
print([dict(r) for r in db.execute('SELECT * FROM wordlists')])

# 获取一册的字段齐全词汇（该词表的教材对应关系仍待核验）。
rows = db.execute('''
    SELECT word, meaning, phonetic, uk_phonetic, us_phonetic
    FROM ready_vocabulary WHERE list_id = ? ORDER BY ordinal
''', ('PEPXiaoXue3_1',))
words = [dict(row) for row in rows]

# 查找一册尚缺音标的记录。
missing = db.execute('SELECT * FROM missing_fields WHERE list_id = ?',
                     ('PEPXiaoXue3_1',)).fetchall()
```

`phonetic` 是便于读取的单一显示字段：词表英音 → 词表美音 → 词表通用音标 → 基础库音标。基础库以英音为主，但未将每条都硬标为英音。`uk_phonetic`、`us_phonetic` 保留来源的明确标注。音标保留原始记法，尚未统一成单一 IPA 规范。`meaning_source`、`phonetic_source` 说明回退后的字段来源。

保留多词义、短语、专有名词、缩写以及词形变化；`word` 保留大小写和重音字符，弯引号与空白仅作保守规范化。没有将词形变化强行归并，也没有把词典通用释义冒充成教材原义。部分上游词条本身可能有错误；原始数据可用于复核。

## 教材缺口与 PDF

官方范围是 2026-09-18 获取的小学 252 条、初中 73 条、五四学制小学 13 条、五四学制初中 41 条。相同版本、年级、册次的多条资源全部保留；候选匹配不会自动获得 `verified` 状态。

已按需下载两本教材试验，均可直接提取文字；小学样本已产生 125 条带单元的词汇草稿，初中样本已保存词汇表分栏文本。这些仍需逐行复核，未混入本库的已导入词表，也未计入已核验覆盖。详见 `完整素材/reports/pdf-probe.json`。

后续按 `完整素材/reports/pdf-action-plan.csv` 补缺，先确认具体版次，再提取书末词汇表，有文字层就分栏提取，扫描页才使用 OCR；音标仍优先取明确来源，疑点人工复核。
