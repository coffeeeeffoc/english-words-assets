# 完整素材与可复现处理过程

最终交付见相邻 `精简词库/`。本目录保存本轮实际获取和产生的全部有效素材，不表示已经下载官方全部 PDF／音频。

## 目录

- `sources/ecdict/`：固定版本 CSV、README、许可证、Git 树、提交来源信息。
- `sources/kajweb/`：固定版本 README、Git 树、22 个原始 ZIP、全部解压 JSON、词表清单和 SHA256。
- `metadata/`：官方分类、原始全站分片、379 本目标教材、详情、关联音频元数据及 18,207 项文件下载清单。
- `materials/`：实际下载的两本教材 PDF，保持原始字节。
- `pdf-extraction/`：两本 PDF 的整本原始文字、词汇表分栏文本、词汇表页图；小学样本另有 125 条待复核词表草稿。
- `reports/`：结构化统计、每册覆盖、每个字段缺失、按版本汇总、PDF 后续任务、下载和数据库验证结果。
- `scripts/`：下载来源、构建 SQLite、离线自检、PDF 试验和最终验证。
- `tools/tchMaterial-parser/`：原解析器及完整浅克隆版本记录，提交 `7d37b0e4de0ccd23cc1e9cd801baecaef43b98f2`。
- `download.py`、`test_download.py`：前一阶段的教材／音频下载脚本与自检。
- `.venv/`：本机下载工具的 Python 依赖环境；不属于数据产品，可以重建。
- `README.md`：前一阶段的过程记录，统计和路径以本说明及最新报告为准。

## 主要报告

| 文件 | 用途 |

| `summary.json` | 基础库、现成词表、缺失字段和教材覆盖统计 |

## 本机运行

在项目根目录执行；基础库构建只使用 Python 标准库，无需安装数据库服务。

```powershell
# 仅使用已下载的素材，重建精简数据库和报告。
python 完整素材/scripts/build_dictionary.py
python 完整素材/scripts/test_build.py
python 完整素材/scripts/verify.py

# 重新获取固定版本源文件（已存在文件跳过，最后运行 verify.py 检查）。
完整素材/.venv/Scripts/python.exe 完整素材/scripts/fetch_sources.py

# 检查教材下载脚本，不发网络请求。
完整素材/.venv/Scripts/python.exe 完整素材/test_download.py
```

若重建下载工具环境：

```powershell
uv venv 完整素材/.venv
uv pip install --python 完整素材/.venv/Scripts/python.exe -e 完整素材/tools/tchMaterial-parser
```

`probe_pdfs.py` 还需要 `pdfplumber`。本轮使用 Codex 随附的 Python，未把该全局运行时复制进本目录。需要在其他机器重现时，可在自己的虚拟环境安装 `pdfplumber==0.11.9`，再运行该脚本。脚本只读原 PDF，并生成文本、PNG 和标注为 `needs_review` 的草稿。

`download.py` 不带参数会尝试下载清单中的全部 PDF 和音频，请不要把它当成词库构建命令。全量目录标注约 67.66 GiB，其中 PDF 约 34.06 GiB；当前磁盘不足以存放全量。词库补缺应只取需要的教材，避免下载听力文件。当前仅有两个 PDF 状态为 `complete`，其余文件元数据不代表已下载。

## PDF 小样发现

接力社版三年级下册与人教版七年级下册均有文字层。整页直接提取会出现分栏阅读顺序错乱、个别词断行；`pdfplumber` 按左右栏提取能够改善这些问题。词汇表页图和原始文本均已保存。小学草稿 125 条，初中保存了分栏文本；尚未完成逐词释义、版次对应和漏行复核，因此没有把任何一个样本记为已核验教材词表。

## 已接受的处理方案

使用 ECDICT 提供基础词条、kajweb 提供历史分册词表、官方目录作为覆盖基准；逐条记录未核验候选和缺口。保留词表原义，空字段才回退基础库。不会凭词序推算单元，不会将九年级全册映射到上册，也不会让普通学制词表自动覆盖五四学制。最终精简目录只保留 SQLite、说明、ECDICT 许可证。
